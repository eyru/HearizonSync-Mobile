## 关键事实（别重复踩坑）

- 模型契约：输入 `x` float32 `[N,T,560]`、`x_length` int32、`language` int32、`text_norm` int32 → 输出 `logits` float32 `[N,T,25055]`
- 前端参数（必须与训练一致）：povey 窗、preemph 0.97、low 20、high −400（相对 Nyquist）、snip_edges、逐帧去直流、自然对数、eps 1.1920929e-07、LFR 左填 3 帧 + 尾部复制末帧、CMVN `(x + neg_mean) * inv_std`
- 翻译：源句末尾必须补 `</s>`(id 0)，否则 decoder 退化成重复循环
- `source.spm` 的 piece id **不等于** `tokenizer.json` 的 id → 必须用三列映射表 `src_spm.txt`
- **ja-en 的 pad/decoder_start 是 60715**，其余三个是 65000；写死 65000 会让日→英解码起点越界、静默输出空串（表现为「日语能识别不能翻译」）
- **VAD 噪声底必须用滑动窗口分位统计，不能用指数平滑**：同一段 10.3 s 语音，指数平滑切 8 段 CER 0.514、分位法切 4 段 CER 0.000
- **降噪对识别率没有稳定收益**（平均 CER 0.417 vs 0.423），且开启会把键盘噪声从 0 条幻觉放大到 3 条 → 默认关闭
- **幻觉字幕只能文本级拦**：置信度、声学特征、`<|nospeech|>`、事件 token 全部实测不可用；真机上还会漏英文填充词（yeah/oh）和日语韩语单字，第二版过滤器按「内容强度」而不是只按段长判（ADR-016）
- **选翻译方向要同时锁定识别语言**：`auto` 会让韩语被判成中文/日文，输出语言全错（ADR-015）
- 自测的耗时数字必须放 `tag` 而不是正文，否则会被导出进 SRT/TXT（已修）
- `adb shell mkdir` 建的目录 other 无 x → `chmod 755`，否则 ORT 报 `system error number 13`
- MSYS 会把 `/sdcard/...` 转成本地路径 → 所有 adb 设备路径前加 `MSYS_NO_PATHCONV=1`
- AGP 拒绝非 ASCII 工程路径 → `gradle.properties` 里 `android.overridePathCheck=true`
- `Properties.load(InputStream)` 按 ISO-8859-1 解码 → 读含中文路径的配置必须用 `reader(Charsets.UTF_8)`
- debug 包与 release 包签名不同 → 换包必须先 `adb uninstall`，否则 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`
- 真机底部（y≈3000–3200）是系统手势区，自动化点击会回桌面；点按钮要取上半部
